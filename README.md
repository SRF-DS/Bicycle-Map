# Bicycle Map

## Problem
Bike trip and station data is geographic by nature — a table of coordinates is not how humans explore a network.

## What we built
A Leaflet-based map UI for browsing bicycle geography (stations / trips) with lightweight static assets under `static/`.

## Live demo
https://srf-ds.github.io/Bicycle-Map/

## How to run locally
Open `index.html` in a browser, or serve the folder with any static file server.

## Stack
JavaScript · Leaflet · HTML/CSS · GitHub Pages

## Fun closer
Sometimes the best insight is just: zoom out, then follow the spokes.
